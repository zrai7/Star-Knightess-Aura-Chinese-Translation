# Star-Knightess-Aura-Chinese-Translation
This project is an AI Chinese Translation for the steam game Star Knightess Aura. 

这是一个星骑士奥拉的AI汉化补丁


使用方法：
1.下载最新的cn_pack_20261024-1621.zip文件并解压
<img width="436" height="71" alt="屏幕截图 2026-10-24 153808" src="https://github.com/user-attachments/assets/5592b1b1-9518-4cdc-a285-b2b870fabcc2" />

2.解压后进入文件夹，找到install.bat
<img width="457" height="185" alt="屏幕截图 2026-10-24 153816" src="https://github.com/user-attachments/assets/97e82681-5e68-4174-82fb-3acd6e5b3e90" />

3.将游戏文件拖动到install.bat上，并等待它运行完成
<img width="487" height="375" alt="屏幕截图 2026-10-24 154129" src="https://github.com/user-attachments/assets/94b96780-fd26-4310-ad4c-37e9a6c535b0" />

4.进入游戏后，找到option，在设置里English换成简体中文，显示翻译进度0.00%是正常现象
<img width="703" height="478" alt="image" src="https://github.com/user-attachments/assets/c18f580b-57a7-4f7a-9429-97955520bf63" />

5.需要注意的是，现在汉化的只有99%的对话，菜单界面并没有完全汉化
